**Laravelify** is an open-source, self-hosted control panel that turns one Ubuntu server into a home for your apps: **Laravel** and PHP, **Express**, **NestJS**, **React**, **Vue.js**, **Angular**, **Svelte**, **Astro**, **Next.js**, **Nuxt**, and **SvelteKit**. Push to GitHub and your site deploys, then watch live traffic, errors, attacks, and server load. No Docker, no per-seat pricing, no vendor lock-in.

```bash
curl -fsSL https://cdn.laravelify.cloud/install.sh | sudo bash
```

> [!NOTE]
> Laravelify is in **public beta**. Try it on a fresh server, keep backups, and [tell us what breaks](https://github.com/laravelify-cloud/laravelify/issues).

### What it does

- 🚀 **Git push to deploy** backends, front ends, and full-stack apps (PHP 8.0–8.5, Node 20–24) with live build logs, or start from a built-in example project
- 📈 **Live monitoring**: requests, p95 response times, uptime, grouped Laravel errors
- 🛡️ **Attack detection** with one-click IP blocking, 💓 heartbeats for cron jobs
- 💬 **Telegram alerts** for deploys, downtime, crashed workers, error spikes
- ☁️ **Cloudflare tunnels**, 🔐 two-factor sign-in, 🧰 file manager, terminal, logs
