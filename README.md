# laravelify-cloud/.github

Organization-wide files for [Laravelify](https://laravelify.cloud), the open-source self-hosted deployment panel. GitHub uses them for every repository in [laravelify-cloud](https://github.com/laravelify-cloud) that has no file of its own.

| File | Used for |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organization page at [github.com/laravelify-cloud](https://github.com/laravelify-cloud): what Laravelify is, the install command, the repositories, and how to get involved |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How we treat each other in issues, discussions, and pull requests |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask a question, report a bug, or report a security problem (shown when someone opens a new issue) |
| [`FUNDING.yml`](FUNDING.yml) | The **Sponsor** button: GitHub Sponsors, Buy Me a Coffee, and the sponsor tiers on [laravelify.cloud](https://laravelify.cloud/#sponsors) |

## The repositories

| Repository | What it is |
| --- | --- |
| [laravelify](https://github.com/laravelify-cloud/laravelify) | The panel, the installer, and the releases |
| [laravelify-docs](https://github.com/laravelify-cloud/laravelify-docs) | The documentation at [docs.laravelify.cloud](https://docs.laravelify.cloud) |
| [laravelify-website](https://github.com/laravelify-cloud/laravelify-website) | The website and install command builder at [laravelify.cloud](https://laravelify.cloud) |

## Changing these files

Edit them here and push to `main`: the organization page and the defaults update right away. Keep `profile/README.md` in step with the panel's own [README](https://github.com/laravelify-cloud/laravelify#readme) when features change.
